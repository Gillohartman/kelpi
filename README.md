# Green Client Tweaks (Fabric, Minecraft 26.1.2)

Client-side mod. Needs Fabric Loader 0.19.2+, Fabric API and Java 25.

- Inventory: **Ctrl+R** in your inventory merges partial stacks and sorts the main slots
- All nametags: neon green
- 2D green hitbox rectangle around visible players (first person)
- Players running this mod get a dried-kelp icon in front of their nametag
- Fire overlay hidden while you burn
- View bobbing forced off
- Vanilla crosshair replaced by a thin green one

## Build
Push to GitHub -> Actions tab -> "Build mod" -> download the `greenmod-jar` artifact -> put the jar in `.minecraft/mods`.
